# DNJ Apps

Minimal static HTML website at https://dnjapps.live for independent apps by Dariusz Kleczek.

No JavaScript, third-party fonts, tracking, build tools or package dependencies. GitHub Pages serves the main branch root. `.nojekyll` disables Jekyll; `CNAME` declares the domain. English homepage; Clover Dash support, privacy and terms in English and Polish. Add future apps as sibling directories with a homepage card.

Preview: `python3 -m http.server 5190` from this directory.
